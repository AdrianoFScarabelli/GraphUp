# GraphUp - Seu site de finanças pessoais

Dashboard de finanças pessoais para registrar receitas e despesas, acompanhar o saldo e visualizar os gastos por categoria e por mês em gráficos.

## Funcionalidades

- Cadastro, edição e exclusão de transações
- Resumo de saldo, receitas e despesas
- Gráficos de gastos por categoria, receitas vs. despesas e evolução do saldo
- Filtros por mês, categoria e tipo
- Login com e-mail e senha ou Google, além de uma conta demo

## Tecnologias

- React
- TypeScript
- Vite
- Firebase (autenticação e banco de dados)
- Deploy na Vercel
